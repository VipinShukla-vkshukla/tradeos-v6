AI vs ML — Precise Role Boundaries

AI owns every task requiring reasoning, context synthesis, or language generation. ML owns pattern scoring, regime classification, and statistical discovery.

🧠 AI — Primary Intelligence (3 tasks)

  • Daily: Signal conviction — Given full context across 10 tables, reason about whether this candidate is worth acting on and why. Explain risks, catalysts, conflicts with portfolio.
  • Daily: Trade lessons — After each exit, read entry context + hold period events + outcome, write structured root-cause lesson with scenario_type, root_cause, corrective_rule.
  • Weekly: Strategy evolution — Analyse 90-day trade performance across 15 tables. Identify parameter drift by strategy+sector+regime. Propose changes with evidence counts.
Provider routing (cheapest → expensive):
DeepSeek → Claude → Grok → Gemini → OpenAI → Azure
Budget gate: daily_cost > limit → ML fallback for conviction only

📊 ML — Three Specific Roles (not a replacement)

  • Role 1 — Conviction backup: When AI fails/budget exceeded, RandomForest scores signal conviction from signal_log features. Requires G1 fix (9 ML cols) to be meaningful. Returns a score, never a reason.
  • Role 2 — Regime classification (Phase 2): Replaces the manual Sheet formula for market_regime. Trained weekly on regime_history. Better than a formula, no reasoning needed.
  • Role 3 — Statistical discovery (Phase 4): discovery_engine.py uses Pearson correlation + Mann-Whitney U to find which chartink columns correlate with outcomes. Pure statistics — better than LLM for this task because actual numbers don't hallucinate.
ML never does: Write lessons · Propose parameter changes · Explain context · Replace AI for any reasoning task
